An AI-assisted SDLC agent team that takes a Jira ticket from intake to a reviewed, mergeable pull request with minimal human hand-holding. Nine specialized agents each own one stage — requirements capture, design, backend/frontend implementation, test writing, code review, and security review — with only the tools and permissions their job needs, so read-only review steps can't accidentally edit code. The pipeline branches automatically for bugs (straight to root-cause-and-fix) versus stories (full design-first flow), and every step's output feeds the next via a shared task brief. Available as both Claude Code subagents and GitHub Copilot custom agents, so the same workflow runs regardless of which assistant the developer prefers.
